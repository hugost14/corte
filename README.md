# Corte

Editor de video UGC para TikTok Shop que funciona en el iPhone, incluso sin internet.

## Instalar en el iPhone
1. Abre esta página en Safari (con WiFi la primera vez).
2. Compartir → Agregar a pantalla de inicio.
3. Ábrela desde el ícono y espera el aviso "Listo: Corte ya funciona sin internet".

Los subtítulos automáticos usan Whisper base (modelo de código abierto) y corren en el propio teléfono: el audio nunca sale del dispositivo.
